E-commerce — Tasks da Equipe

Implementação acadêmica baseada no projeto de referência, usando somente PHP, MySQL, HTML, CSS, JavaScript e Bootstrap.

Laravel foi removido propositalmente desta versão. A organização MVC, Services, rotas e API serão implementadas manualmente em PHP.

Premissa técnica

Embora o documento original peça Laravel, esta equipe utilizará o mesmo escopo funcional como referência: autenticação, catálogo, produto, carrinho de visitante, fusão no login, checkout, pagamento simulado, pedidos, administração e perfil. A implementação será feita em PHP puro, mantendo separação de responsabilidades.

Arquitetura combinada

Backend

  • PHP 8+
  • PDO para MySQL
  • API REST retornando JSON
  • MVC manual: Controllers, Models e Services
  • Sessão PHP e/ou token opaco próprio
  • Transações com PDO em checkout e cancelamento

Frontend

  • HTML5 + Bootstrap 5
  • JavaScript com Fetch API
  • LocalStorage/cookie somente para identificadores necessários
  • Telas responsivas
  • Sem framework JS adicional
  • Sem Laravel, React, Vue ou similares

Definition of Done

  • Código está na branch correta e passou por revisão do Tech Lead.
  • Endpoint retorna JSON padronizado e código HTTP adequado.
  • Queries usam PDO com prepared statements.
  • Validação é feita no backend, não apenas no JavaScript.
  • Regra de negócio relevante está em Service.
  • Rotas privadas verificam autenticação e autorização.
  • Fluxo principal foi testado manualmente.
  • Frontend não calcula preço ou total como fonte de verdade.
  • Nenhum dado de cartão é solicitado ou armazenado.
  • README é atualizado quando houver nova configuração ou regra importante.
